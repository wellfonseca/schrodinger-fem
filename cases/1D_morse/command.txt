# =============================================================================
#  Case: 1D_morse   (Elmer FEM, 1D)
#  Domain side L = 10.0   elements per direction n = 400   origin x0 = 0.0
#  Potential: V = 10*(exp(-2*0.5*(x-3)) - 2*exp(-0.5*(x-3)))
#  Analytic reference: E_nu = 2a sqrt(D_e)(nu+1/2) - a^2(nu+1/2)^2 - D_e, full line
#  Expected: E_0 = -8.481361 (full line); -8.481034 on [0,10] with 400 elements
# =============================================================================
#
#  Requirements: Elmer (ElmerGrid, ElmerSolver) and Gmsh on the PATH.
#  The mesh is regenerated from the Gmsh source committed here; the .msh file
#  is already present, so step 1 is optional.
#
#  1. Regenerate the mesh with Gmsh (optional)
#       python3 generate_mesh.py
#     This writes the Elmer-format mesh into mesh/. To go through Gmsh
#     explicitly instead:
#       gmsh 1D_morse.geo -2 -o 1D_morse.msh
#
#  2. Convert the mesh to the Elmer format expected by case.sif
#       ElmerGrid 14 2 1D_morse.msh -out mesh
#     (14 = Gmsh input, 2 = Elmer output; case.sif reads Mesh DB "." "mesh")
#
#  3. Solve
#       ElmerSolver case.sif
#
#  4. Inspect
#       - eigenvalues are written to run.log
#       - a ParaView file is written to mesh/*.vtu
#
#  With the container built from ../../src/elmer_schrodinger_files.def:
#       apptainer exec elmer_schrodinger.sif ElmerSolver case.sif
#
#  NOTE: use the serial ElmerSolver. ElmerSolver_mpi with more than one rank
#  returns wrong results, because the module assembles dense local matrices.
#  See ../../docs/PARALLELISM.md.
# =============================================================================
