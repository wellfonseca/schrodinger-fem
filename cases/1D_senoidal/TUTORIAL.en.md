# Tutorial — Periodic potential — band structure

**Directory:** `1D_senoidal`
**Solvers:** SchrodingerSolver, ResultOutputSolve
**Tools:** ElmerSolver, ParaView
**Dimensions:** 1D, Steady state
**Type:** generalised eigenvalue problem

---

## 1. Case definition

The domain is `[−L/2, +L/2]` with

| Parameter | Value |
|---|---|
| Length `L` | `20.0` |
| Elements per direction | `400` |
| Origin | `-10.0` |
| Potential | V = 0.5·cos(2πx/10)  (period 10) |

The problem to be solved is the steady-state Schrödinger equation

    −∇²ψ + V(r) ψ = E ψ

whose weak form leads to the generalised eigenvalue problem `A ψ = E M ψ`, with
`A = K + Mᵃ`. The details of the formulation are in
`Manual_Modelo_Schrodinger.md`.

### Analytical solution

    band structure (no elementary analytical solution)

**Reference value:** V ∈ [−0.5, +0.5]

---

## 2. Solution procedure

> ⚠ **Every simulation must run on the compute nodes, never on the headnode.**

### 2.1 Generate the mesh

The mesh is generated by the script `gerar_malha.py`, which writes Elmer's
native format (`mesh.header`, `mesh.nodes`, `mesh.elements`, `mesh.boundary`):

```bash
python3 gerar_malha.py
```

### 2.2 The input file (SIF)

**`Header`** and **`Simulation`**:

```
Header
  Mesh DB "." "malha"
End

Simulation
  Coordinate System = Cartesian 1D
  Simulation Type = Steady State
  Steady State Max Iterations = 1
  Max Output Level = 5
End
```

The `Coordinate System` **must** match the dimension of the mesh.

**`Body`, `Material` and `Body Force`**:

```
Body 1
  Equation = 1
  Material = 1
  Body Force = 1
End

Material 1
  Density = 1.0
End

Body Force 1
  Potential = Variable Coordinate 1
    Real MATC "0.5*cos(2*3.14159265358979*tx/10.0)"
End
```

**`Equation`** — two active solvers:

```
Equation 1
  Active Solvers(2) = 1 2
End
```

**`Solver 1`** — the Schrödinger solver:

```
Solver 1
  Equation = "Schrodinger"
  Procedure = "SchrodingerSolver" "SchrodingerSolver"
  Variable = "psi"
  Variable DOFs = 1
  Eigen System Values = 5
  Apply Dirichlet = Logical True
  Linear System Solver = Direct
  Linear System Direct Method = "umfpack"
End
```

`Eigen System Values = 5` requests the **five lowest** eigenvalues.
`Apply Dirichlet = Logical True` imposes `ψ = 0` on the boundary, detected
automatically by the geometry — there is **no** need to declare a
`Boundary Condition`.

**`Solver 2`** — the output for ParaView:

```
Solver 2
  Exec Solver = "After Simulation"
  Equation = "ResultOutput"
  Procedure = "ResultOutputSolve" "ResultOutputSolver"
  Output File Name = File "run"
  Output Format = String "vtu"
End
```

### 2.3 Run

Via PBS (recommended — runs on a compute node):

```bash
qsub roda_caso.pbs
```

Interactively, inside a node (`qsub -I`):

```bash
$ES caso.sif > run.log 2>&1
```

**Expected:** V_min = −0.500000, V_max = +0.500000; E₁ ≈ −0.213

### Potential check

The solver reports the extrema of the read `V` field in the log:

```
SchrodingerSolver: V(x) lido como campo nodal de Body Force.
#   (log output is literally: "V(x) read as nodal field from Body Force")
SchrodingerSolver:   V_min = ...
SchrodingerSolver:   V_max = ...
```

Check these values **before** trusting the eigenvalues.

### Remarks

Periodic potential with **two periods** in the domain (`cos(2πx/10)` on
`[-10, +10]`). This is the case that connects the solver to the physical problem
of interest to the project — the **lattice potential** (the Sehra case).

The check here is **not** an analytical eigenvalue (no elementary closed form
exists), but the **amplitude of the potential**: `V_min = −0.5` and
`V_max = +0.5` exactly.

**Physical remark:** the eigenvalues form **groups** (bands) separated by gaps.
`E₁` and `E₂` are very close (`−0.2132` and `−0.2094`), while `E₃` jumps to
`+0.2851`. Increasing the number of periods narrows the bands and makes the gaps
sharper.

## 4. Visualisation

The case produces the VTU file (mesh + the `psi` field, eigenfunction of mode 1):

```bash
paraview malha/run_t0001.vtu
```

> Elmer writes the `.vtu` in the **mesh directory**, which is why the path is
> `malha/run_t0001.vtu` and not `run.vtu` in the root.

In ParaView: select `psi` under **Coloring** to see the eigenfunction. Use the
*Contour* or *Slice* filters (in 3D) to inspect the nodal structure.

### What to look for

With **two** periods, the eigenfunctions are expected to resemble the Bloch
functions of the periodic potential. Mode 1 should have a maximum at each
minimum of the potential (at `x = ±5`) and a node at `x = 0`, where the
potential is maximum.

Increase `L` (and the number of elements) to see more periods and the band
structure consolidate — this is the path towards the crystal lattice case.
